WIINDOWS 10
===========

Un escritorio interactivo inspirado en Windows 10, creado con HTML, CSS y JavaScript puro.

El proyecto funciona como una página estática y puede publicarse directamente en GitHub Pages.


CONTENIDO
---------

- Escritorio interactivo.
- Barra de tareas con reloj y buscador.
- Aplicaciones integradas:
  - Navegador.
  - Explorador de archivos.
  - Reloj.
  - Bloc de notas.
  - Calculadora.
  - Calendario.
  - YouTube interno.
- Microsoft Store.
- Papelera de reciclaje.
- Instaladores con estilo de Windows.
- Escritorios virtuales.
- Fondos de pantalla.
- Descarga y visualización de imágenes y videos.
- Menús contextuales para anclar, desanclar, abrir y borrar aplicaciones.
- Estado guardado en el navegador mediante localStorage.
